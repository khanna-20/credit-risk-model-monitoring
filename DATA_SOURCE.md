# Data source and attribution

## Dataset
- **Name:** Polish Companies Bankruptcy
- **Publisher:** UCI Machine Learning Repository (dataset ID 365)
- **Official page:** https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data
- **DOI:** https://doi.org/10.24432/C5F600
- **Creator:** Sebastian Tomczak
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0). Redistribution is permitted with attribution, which is why the file is included in this repository.
- **Citation:** Tomczak, S. (2016). *Polish Companies Bankruptcy* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5F600
- **Introductory paper:** Zięba, M., Tomczak, S. K., & Tomczak, J. M. (2016). Ensemble boosted trees with synthetic features generation in application to bankruptcy prediction. *Expert Systems with Applications*.

According to UCI, the data comes from the Emerging Markets Information Service (EMIS). Bankrupt companies were analysed over 2000-2012 and still-operating companies over 2007-2013.

## Horizon files (from the UCI documentation)

| File | Ratios from | Label: bankruptcy status after | Firms | Bankrupt |
|---|---|---|---|---|
| 1year.arff | 1st year of forecasting period | 5 years | 7,027 | 271 |
| 2year.arff | 2nd year | 4 years | 10,173 | 400 |
| 3year.arff | 3rd year | 3 years | 10,503 | 495 |
| 4year.arff | 4th year | 2 years | 9,792 | 515 |
| **5year.arff (used)** | **5th year** | **1 year** | **5,910** | **410** |

Only `5year.arff` is used, because its one-year horizon matches the 12-month PD convention used in bank credit models. The files describe different prediction horizons and are not merged.

## How the file in this repository was obtained
The sandbox used to build this project could not reach `archive.ics.uci.edu` directly. The file was therefore taken from a public GitHub mirror of the original ARFF files (`kamileyagci/project-bankruptcy-prediction`, folder `data/`) and **verified against the official UCI documentation**:

- All five mirror files match UCI's documented instance and bankrupt counts exactly (see table above).
- The attribute layout is `Attr1`-`Attr64` plus `class`, as in the UCI ARFF release.
- SHA-256 of `data/raw/5year.arff` used in this project:
  `cb3f6f250ac46bd8d18e9a222f489fe8ee3e396fcec18959f5a0ef8e8169b2fc`

If `data/raw/5year.arff` is deleted, `python -m creditrisk develop` downloads the official UCI zip from
`https://archive.ics.uci.edu/static/public/365/polish+companies+bankruptcy+data.zip` and extracts `5year.arff`. **This automatic download route was not tested from the build environment** (UCI was unreachable there). If it fails, download the zip from the official page, extract `5year.arff` and place it in `data/raw/`. The test `tests/test_real_data.py` confirms the documented counts (5,910 firms, 410 bankrupt).

## Changes made by this project
- Columns renamed `Attr1..Attr64` to `X1..X64` (matching the UCI attribute list), and `class` to `default_flag`.
- 60 exact duplicate rows are removed in memory before modelling. The file itself is unchanged.
- Feature X24 is excluded from modelling as a leakage precaution (see README).

## Simulated data
Files in `data/simulated/` (regenerated by `python -m creditrisk simulate`) are **synthetic monitoring batches**. They are created by resampling held-out rows of this dataset and applying documented scenario changes. They are not real bank or production data.
